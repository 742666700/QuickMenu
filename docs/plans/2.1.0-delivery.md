## 实现说明

M1 将决定何时播放的逻辑留在不依赖 WPF 的 `CompanionSchedule`，窗口执行片段、眨眼、过渡与矢量 Burst；角色各自读取 `Temperament`。后台在原始 1200 px 空间替换补丁 RGBA，再整体解码到 860 px 并冻结，显示路径保持完整图切换和 90 ms 交叉淡化。切换姿势释放上个姿势的片段资源；初次显示仍同步加载基础姿势，动作未准备好便跳过。

输入统一覆盖键盘、鼠标、触摸和现有手柄导航入口；隐藏后停表，无输入两分钟停片段/循环，睡着的饭碗版停在睡眠帧。系统禁用动画时使用静态终值；“AI娘小动作”关闭后保留主动悬停/点击反馈。新增设置沿用旧配置兼容与单字段修复。

用户指定的两项修正均在 M1：`DesktopService.cs:142` 使用 `new ComScope(0)`；`MotionPreferenceChanged` 只对 `ClientAreaAnimation`、`MenuAnimation`、`ComboBoxAnimation` 刷新，渲染层级变化独立处理。

自发动作在光点实际 Burst 回调内启动。曾试验主体缓存、过渡裁切和较低滤镜质量，收益不稳定，均已移除；最终仍使用完整图和 HighQuality，没有保留试验性渲染分支。
