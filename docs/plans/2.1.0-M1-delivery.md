# 2.1.0 · M1 动画引擎阶段索引

用户随后要求连续推进 M1–M6、全部实现后统一测试，因此当前权威交付说明为 [2.1.0 统一交付记录](2.1.0-delivery.md)。本页不宣称 M1 已通过用户验收，也不把后续美术混称为 M1 的“无新图”产出。

M1 包含纯调度器、角色节奏、补丁工具与后台合成、片段播放器、矢量特效、输入唤醒、两分钟停表、设置兼容及 QA。指定的 ComScope(0) 和动画属性过滤修正也在同一分支完成。

既有五张 blink 转成补丁后在 1200 px 原空间精确还原 RGBA；eat-2–6 的差异包围盒超过 60%，按计划保留原整帧。转换报告在 `artifacts/m1/art-checks/`，原始备份在忽略目录 `art-work/m1-originals/`。

M1 中间快照的测试、QA 和性能调查位于 `artifacts/m1/`。它们只证明当时的快照；最终 2.1.0 使用 `artifacts/2.1.0/` 下的统一验证证据。早期性能数据没有达到 CPU 约束，所有原始报告保留，不作为当前通过凭证。

分支仍是 `codex/2.1.0-motion`。版本号、提交、文件清单、当前测试结果、每动作 GIF、包体及计划差异统一记录在上面的交付文档中。没有发布、推送或打 tag。
