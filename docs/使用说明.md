# 快捷菜单使用说明

[English](user-guide.md)

快捷菜单是一个 64 位 Windows 11 桌面工具：按快捷键在屏幕中央呼出菜单，打开桌面项目和游戏，切换正在运行的应用。普通用户权限即可使用。

## 开始使用

1. 运行安装包 `QuickMenu-Setup-<版本>-x64.exe`，装好后从开始菜单打开；它会自动检查并安装 .NET 10 桌面运行时。也可以解压便携包，直接运行 `QuickMenu.exe`。第一次运行会弹出简短的欢迎提示。
   - 完整版（`-x64.zip`）自带 .NET 运行时，解压即用。
   - 轻量版（`-x64-small.zip`）需要先安装 [.NET 10 桌面运行时](https://dotnet.microsoft.com/download/dotnet/10.0)（x64，也可以用 `winget install Microsoft.DotNet.DesktopRuntime.10`）。没装时启动会弹出 .NET 提示框和下载按钮；装好后再运行即可。两者功能完全一样。
2. 默认快捷键 **Alt + 空格**：按一次呼出，再按一次（或 Esc）收起。
3. 收起后程序在任务栏右下角的托盘里待命。托盘菜单可以打开菜单、打开设置或退出。
4. 菜单出现在鼠标所在显示器的中央；按住顶部空白处可以拖动。

## 桌面页

- 列出桌面上的快捷方式、文件、文件夹和系统图标，以及游戏库里的游戏。单击或回车打开；直接打字即可搜索。
- 顶部标签：**全部、游戏、AI工具、分类⌄、文档+**，以及你自己建的、设为标签的分类。“文档+”悬停时展开文档、表格、演示文稿。
- **置顶**：右键 › 置顶，项目出现在顶部的置顶栏里。
- **排序**：右上角“常用优先⌄”可选最常用、修改时间、类型或自定义；长按项目拖动即切换为自定义顺序。
- **右键菜单**：置顶、标记分类、标记 / 取消 AI 工具、从游戏库隐藏（游戏库里的游戏）、打开文件所在位置、结束进程（程序正在运行时）。
- 把 AI 工具的快捷方式放进桌面上名为“AI工具”或“AI Tools”的文件夹，菜单会直接列出里面的快捷方式。

## 运行应用页

显示有窗口的应用（含最小化窗口）和能读取到的托盘程序。同一进程的多个窗口会合并，打开时可以选择具体窗口。结束进程前一定会确认；只结束所选进程，不会提权。

## 键盘

| 按键 | 作用 |
| --- | --- |
| 快捷键（默认 Alt + 空格） | 呼出 / 收起菜单 |
| Tab | 切换桌面和运行应用 |
| 方向键 | 移动选中框 |
| Enter | 打开项目或切换窗口 |
| Esc | 关闭对话框，或收起菜单 |
| F5 | 重新扫描桌面和游戏 |
| Shift + F10 / 菜单键 | 打开选中项目的右键菜单 |

## 手柄（Windows 掌机、Xbox 手柄）

| 按键 | 作用 |
| --- | --- |
| 菜单键 + 视图键（同时按） | 呼出 / 收起菜单，任何时候都可以 |
| 十字键 / 左摇杆 | 移动选中框，按住连续移动；右键菜单、下拉列表、对话框和设置页里同样可用 |
| A | 打开选中的项目，或确认 |
| B | 打开选中项目的右键菜单；菜单、下拉列表或对话框打开时关闭它；在设置页返回桌面 |
| LB / RB | 切换桌面和运行应用 |
| LT / RT | 切换桌面页顶部的分类标签（全部、游戏、AI工具……）；在设置页跳到上一个 / 下一个部分 |
| Y | 打开 / 离开设置 |

支持 XInput 手柄（Xbox 手柄和大多数 Windows 掌机）。可以在“设置 › 通用 › 手柄”里关闭。

## 设置

右上角齿轮打开设置，左侧可以跳到各部分。所有改动立即生效并保存。

- **通用**：免费声明、语言（跟随系统 / 简体中文 / English）、呼出快捷键（必须包含 Ctrl 或 Alt，和其他程序冲突时保留原快捷键）、问候语里是否显示时间（可以给本机时间起名字，再加一个时区）、点击菜单外面时是否自动收起（默认收起；关闭后菜单会退到你点击的窗口后面，再按快捷键或点托盘图标回到最前面，搜索内容和所在页面都保留）、开机启动、手柄。
- **外观**：主题（跟随系统、OLED · 白天、OLED · 黑夜、奶油雏菊、珍珠白、深海蓝白、星夜紫）和 AI娘形象（可以搭配任意主题；可选切换主题时自动换成对应的形象）。“AI娘小动作”默认开启；关闭后停止自发动作、打瞌睡和主题联动，鼠标悬停与点击反应仍保留。系统关闭了动画效果时，所有角色动作和主题动效都会停止。
- **游戏库**：
  - 自动读取 Steam（所有游戏库）、Epic、GOG、Ubisoft Connect、Xbox / 微软商店的游戏，以及 EA、战网、米哈游、WeGame 等在 Windows 程序列表里登记了主程序的游戏，每个平台都能单独关闭。
  - 添加游戏文件夹：扫描 Unity、虚幻、Godot、GameMaker、RPG Maker、Ren'Py、吉里吉里等引擎做的游戏。
  - 添加游戏：直接选某个游戏的 exe 或快捷方式。
  - 隐藏的游戏在这里恢复。
- **分类**：
  - 内置规则可以编辑或恢复默认：游戏（快捷方式指向哪些文件夹）、AI 工具（名称里的词）、文档 / 表格 / 演示文稿 / 视频图片（扩展名）。“游戏”“AI工具”标签可以隐藏。
  - 新建分类：名称里的词、扩展名、路径里的文字，符合任意一条即归入；可以设为标签、上移下移、删除。
  - 优先顺序：右键手动归类 › 自己建的分类 › 自动识别。
- **关于**：版本、项目主页、联系邮箱、许可说明、打开配置文件夹。

## 数据与卸载

所有数据保存在 `%LOCALAPPDATA%\QuickMenu`：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 快捷键、主题、语言等设置 |
| `desktop-preferences.json` | 置顶、排序、手动归类、打开次数 |
| `game-library.json` | 读取哪些平台、游戏文件夹、手动添加和隐藏的游戏 |
| `categories.json` | 自己建的分类和修改过的内置规则 |
| `Logs\app.log` | 错误日志 |

卸载：在设置里关闭开机启动，从托盘退出，然后删除程序文件夹；想清除设置就再删除上面的文件夹。开机启动只使用当前用户启动项里名为 `QuickMenu` 的值。

程序没有代码签名，第一次运行时 Windows 可能提示“未知发布者”。

## AI娘形象

不同角色有各自的动作节奏：DeepSeek娘慢半拍、爱吃饭和打瞌睡；Claude娘翻书、点头；ChatGPT娘轻柔回应；Gemini娘会抖耳朵和摇尾巴。饭碗版 DeepSeek娘按本机时间在饭点更容易吃饭，午休和深夜更容易出现坐着打瞌睡的姿势。搜索框有内容时，正面姿势的 Claude娘会保持专注。

菜单连续两分钟没有键盘、鼠标或手柄输入时，角色的片段、循环及主题动效会停止，只保留适用姿势的眨眼；睡着的 DeepSeek娘保持睡姿。有输入后恢复，隐藏菜单会立即停止全部动效。角色窗口不会抢走菜单的键盘焦点。

AI娘形象和对应主题是粉丝创作，与 Anthropic、OpenAI、DeepSeek、Google 无关，相关名称和商标归各自所有者。
